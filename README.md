### Lessons for Team 4308 IT Subteam
This is a repository that links to all of the lessons for team 4308's IT subteam.
Updates will be added after each weekly meeting. This repo will also contain
examples to each week's homework.

## Submitting Homework
Create a GitHub repository to store all of your homework. Store each weeks homework
in a folder of this repository as lesson-xx. For example, the homework for lesson 2
should be in folder lesson-02. Share this GitHub repository with me and re-submit
the link to the repository on each google classroom assignment that you are
submitting.
